A lightweight desktop-first wallpaper tool for expanding your favorite image into a larger canvas while keeping the original composition centered and seamless. Hd Extend is designed for clean edge blending, precise positioning, and instant PNG export.

## ✨ Features

- Drag and drop or select any image to extend
- Choose from preset resolutions like desktop, 4K, ultrawide, phone, tablet, and square formats
- Fine tune canvas size, position, edge smoothing, seizure-free blending, and grain match
- Lock aspect ratio and lock sliders for quick adjustments
- Preview the original image positioning box while working
- Export the final result as a PNG
- Works directly in the browser and can be packaged for Android with Capacitor

## 🚀 Quick Start

### Browser

Open the app directly from the repository or serve it locally:

```bash
git clone https://github.com/BR1JM0H4N/Hd-Extend.git
cd Hd-Extend
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

### Android (Capacitor)

```bash
npm install
npm run sync
```

This syncs the web app into the Android project for native packaging.

## 🧩 Project Overview

Hd Extend is a single-page HTML/CSS/JavaScript application that focuses on generating large wallpapers from existing images. It uses a smart edge-blend workflow to keep subject areas intact while growing the canvas and filling the expanded space with visually compatible background tones.

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Capacitor

## 📌 Notes

- The original photo is never altered or scaled down during the workflow.
- Output is generated as a new enlarged canvas built around the source image.
- Best results are achieved with clean edges and simple backgrounds.
